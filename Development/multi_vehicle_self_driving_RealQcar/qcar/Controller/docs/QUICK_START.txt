┌─────────────────────────────────────────────────────────────┐
│ 📊 What Each Parameter Does                                 │
└─────────────────────────────────────────────────────────────┘

s0          Minimum spacing between vehicles
            ↑ Increase → More safe distance
            ↓ Decrease → Tighter formation

h           Time headway (spacing = s0 + h × velocity)
            ↑ Increase → Spacing grows with speed
            ↓ Decrease → Spacing less speed-dependent

K[0]        Spacing error gain
            ↑ Increase → Faster spacing correction (may oscillate)
            ↓ Decrease → Gentler spacing correction

K[1]        Velocity error gain
            ↑ Increase → Better velocity tracking
            ↓ Decrease → Less aggressive velocity matching

acc_to_throttle_gain    Converts acceleration to throttle
            ↑ Increase → More responsive
            ↓ Decrease → Smoother

max_throttle    Maximum throttle output
            ↑ Increase → Can accelerate/brake harder
            ↓ Decrease → Smoother, gentler

┌─────────────────────────────────────────────────────────────┐
│ 🐛 Troubleshooting                                          │
└─────────────────────────────────────────────────────────────┘

Problem: Vehicle oscillates
Solution: Reduce K gains → K: [[0.1, 0.02]]

Problem: Can't maintain spacing
Solution: Increase K[0] → K: [[0.3, 0.05]]

Problem: Can't match speed
Solution: Increase K[1] → K: [[0.2, 0.08]]

Problem: Too aggressive
Solution: Lower max_throttle → max_throttle: 0.2

Problem: Import error
Solution: Make sure longitudinal_controllers.py is in Controller/
