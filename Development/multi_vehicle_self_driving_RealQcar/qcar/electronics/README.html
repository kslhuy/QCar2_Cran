01 · Hệ thống

Hệ thống hoạt động như thế nào?

Twin nhận plant truth từ simulator, sau đó tự tạo measurement, noise, timing và fault. Dữ liệu PCB mặc định là auxiliary, không ghi đè sensor có sẵn của MockQCar.

02 · Build & Run

Chạy hệ thống bằng hai lệnh.

Mở PowerShell tại thư mục gốc QCar2_Cran. Cần environment Qcar, CMake/Ninja và Node.js/npm.

03 · Kiểm tra

Những gì cần thấy trên UI.

Runtime

  • Firmware = native_cpp
  • Sensor và compute node là running
  • V2V path = firmware
  • Telemetry có frame mới

Native authority

  • T / W / C / P checks tăng
  • Authority gate = READY
  • Chọn C++ authority rồi Apply core
  • Native-use tăng, failback bằng 0
Safety: nếu C++ lỗi hoặc parity mismatch, authority tự trở về Python. Sau khi sửa lỗi, dùng Reset parity.
04 · Hardware / HIL

Cùng một core có thể chạy trên phần cứng thật.

Backend hil_external kết nối MCU/SoC qua CRHL. UDP có sẵn; UART, CAN hoặc PCIe dùng adapter. STM32 hiện tại chỉ là một profile.
